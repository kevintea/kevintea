# Hi, I'm Kevin Tea 👋

### QA Automation & AI-Assisted Engineering from Argentina 🇦🇷

I design maintainable QA systems that help teams and AI-assisted workflows deliver software with confidence.

My work connects **test automation**, **functional analysis**, **portable processes**, and **quality governance**. I focus on making autonomous work reproducible, reviewable, privacy-aware, and safe for real delivery pipelines.

## What I do

- Design risk-based test strategies from requirements and product behavior
- Build and maintain end-to-end automation with Playwright and TypeScript
- Define portable QA standards, runbooks, and evidence-driven workflows
- Organize AI-assisted work with explicit scope, deterministic checks, and human approval boundaries
- Turn functional analysis into traceable scenarios, acceptance criteria, and regression coverage
- Integrate quality gates into GitHub Actions and CI/CD pipelines
- Promote accessibility, privacy, and security-aware testing practices
- Combine manual, exploratory, API, and automated testing according to risk
